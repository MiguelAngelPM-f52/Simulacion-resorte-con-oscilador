# Simulación de Péndulo Articulado sobre Base Móvil con Resorte

Repositorio que modela analítica y numéricamente el comportamiento dinámico de una masa $m_1$ acoplada a un resorte horizontal de la que cuelga un péndulo simple de masa $m_2$.
